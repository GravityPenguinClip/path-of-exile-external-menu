## 🧩 About

**Path of Exile desktop helper** is a curated list of Path of Exile open-source tools:

- **Overlays** — on-screen helpers, layout notes, map overlay, stash notes
- **Quality-of-Life Helpers** — loot filter notes, build planner notes, overlay notes
- **Research Notes** — passive tree notes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Map & Loot Helpers
- Map Overlay — on-screen layout notes for study
- Loot Filter Notes — organize item filters
- Stash Notes — track stash tab layouts
- Playback Speed — adjust overlay refresh for study (0.1x to 5x)

### 🎨 Build & Catalog
- Build Planner Notes — browse passive tree notes
- Item Catalog — organize gear and currency notes
- Skill Gem Notes — improved layout visibility

### 🏋️ Practice Layout
- Atlas Notes — segment study on any layout
- Delve Layout Notes — manually switch routes in study
- Flask Timer Notes — chain complex maneuvers in notes
